# 📖 About

**Network Sniffer** is a modern desktop-based network packet analyzer developed using **Python**, **Scapy**, and **CustomTkinter**.

It allows users to monitor live network traffic, inspect packets, analyze protocols, identify top communicating hosts, visualize traffic statistics, search packets efficiently, generate reports, and export captured data.

This project was developed for learning cybersecurity, networking, packet analysis, and Python desktop application development.
